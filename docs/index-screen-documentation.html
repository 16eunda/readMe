🎯 화면 개요

index.tsx는 ReadMe 앱의 메인 홈 화면으로, 사용자가 전자책(TXT, EPUB)을 관리하고 읽을 수 있는 핵심 화면입니다.

📌 주요 역할
  • 파일 목록 조회 및 표시
  • 파일 추가 (TXT, EPUB 지원)
  • 폴더 구조로 파일 관리
  • 검색 기능
  • 파일 읽기 및 이어읽기
  • 파일/폴더 옵션 (편집, 이동, 삭제)

⚡ 주요 기능

📂 파일 관리

파일 추가: 플로팅 버튼(+)을 눌러 TXT 또는 EPUB 파일을 선택하면 자동으로 미리보기를 생성하고 서버에 저장됩니다.

  • TXT 파일: 다중 인코딩 자동 감지 (CP949, UTF-8, EUC-KR, Windows-1252)
  • EPUB 파일: JSZip으로 압축 해제 후 첫 챕터 추출
  • 중복 체크: 같은 이름의 파일이 있으면 확인 모달 표시

📖 파일 읽기

단순 클릭: 파일 카드를 클릭하면 다음과 같이 동작합니다:

  • 처음 읽는 경우: 바로 Reader 화면으로 이동
  • 이어읽기: 진행도가 있으면 마지막 위치의 미리보기를 보여주는 모달 표시

롱프레스: 파일을 길게 누르면 편집 모달이 열림 (제목, 평점, 리뷰 수정)

옵션 버튼: 파일 카드의 옵션 버튼을 누르면 이동/삭제 선택 가능

📁 폴더 관리

폴더 생성: 상단의 "폴더생성" 버튼으로 새 폴더 생성

폴더 이동: 폴더를 클릭하면 해당 폴더 내부로 이동

폴더 옵션: 폴더를 길게 누르면 이름 변경 또는 삭제 가능

  • 폴더 안에 파일이 있으면 삭제 불가
  • 폴더는 계층 구조로 관리됨 (root → 하위 폴더)

🔍 검색 기능

상단 검색창에 텍스트를 입력하면 현재 폴더 내의 파일을 제목으로 필터링합니다.

  • 대소문자 구분 없음
  • 검색 결과가 없으면 "검색 결과가 없습니다" 메시지 표시
  • 검색어 변경 시 표시 개수 초기화 (10개)

∞ 무한 스크롤

파일 목록을 스크롤하여 끝에 도달하면 자동으로 10개씩 추가 로드됩니다.

  • 초기 표시: 10개
  • 스크롤 시: +10개씩 증가
  • 검색/폴더 변경 시: 다시 10개로 초기화

🔐 인코딩 자동 감지

한국어 텍스트 파일의 다양한 인코딩을 자동으로 감지합니다.

시도 순서: 1. UTF-8 BOM 체크 (EF BB BF) 2. CP949 (한국 Windows 기본) 3. UTF-8 4. EUC-KR 5. Windows-1252 → 깨진 문자(�) 비율이 1% 미만이면 성공으로 판단

🔄 작동 흐름

화면 로딩 시

1. 컴포넌트 마운트 (useEffect 실행)
2. fetchFiles() - 서버에서 전체 파일 목록 가져오기
3. fetchFolders() - 서버에서 전체 폴더 목록 가져오기
4. 현재 폴더(currentFolder)에 해당하는 파일/폴더만 필터링하여 표시

파일 추가 흐름

1. 플로팅 버튼(+) 클릭 → pickFile() 실행
2. DocumentPicker로 파일 선택
3. 서버 API로 중복 체크 (/files/check)
4-A. 중복 있음 → DuplicateConfirmModal 표시
4-B. 중복 없음 → addFileToSystem() 실행
5. 파일을 앱 전용 폴더로 복사
6. 미리보기 생성 (TXT: 인코딩 감지, EPUB: JSZip 파싱)
7. saveFileToServer() - 서버에 파일 정보 저장
8. 로컬 상태 업데이트 (setFiles)
9. 화면에 새 파일 카드 표시

파일 클릭 시 흐름

1. FileCard 클릭 → handleFilePress() 실행
2. 서버에서 파일 정보 가져오기 (GET /files/{id})
3-A. progress === 0 → 바로 Reader 화면으로 이동
3-B. progress > 0 → 이어읽기 미리보기 모달 표시
4. PreviewModal에서 "처음부터" 또는 "이어서" 선택
5. Reader 화면으로 이동 (fileId, uri, name 전달)

폴더 이동 흐름

1. 폴더 카드 클릭
2. router.push({ pathname: "/", params: { folder: folder.id } })
3. useLocalSearchParams로 folder 파라미터 읽기
4. currentFolder 업데이트
5. useMemo로 해당 폴더의 파일/폴더만 필터링
6. 화면 다시 렌더링

🌐 API 연동

백엔드 서버 주소

Platform별 주소: - Web: http://localhost:8080 - Android 에뮬레이터: http://10.0.2.2:8080 - iOS 시뮬레이터: http://127.0.0.1:8080 - 기타: http://192.168.35.99:8080

사용 API 엔드포인트

메서드 경로 설명 함수
GET /files 전체 파일 목록 조회 fetchFiles()
GET /files/{id} 특정 파일 정보 조회 (진행도 포함) handleFilePress()
GET /files/check?title={}&path={} 파일 중복 체크 pickFile()
POST /files 새 파일 추가 saveFileToServer()
PATCH /files/{id} 파일 정보 수정 (제목, 평점, 리뷰, 경로) updateFileInfo(), FileMoveModal
GET /folders 전체 폴더 목록 조회 fetchFolders()
POST /folders 새 폴더 생성 saveFolderToServer()
DELETE /folders/{id} 폴더 삭제 deleteFolderFromServer()
⚠️ 주의사항
  • 폴더 삭제 시 하위 파일이 있으면 삭제 불가
  • 파일 삭제는 로컬 상태에서만 제거 (서버 API 미구현)
  • 모든 API 호출은 try-catch로 에러 처리

🔧 핵심 함수

1. decodeTextSafe(buffer: Buffer): string

텍스트 파일 인코딩 자동 감지 함수

  • UTF-8 BOM이 있으면 즉시 UTF-8로 디코딩
  • 없으면 CP949, UTF-8, EUC-KR, Windows-1252 순서로 시도
  • 각 인코딩별로 깨진 문자(�) 비율 계산
  • 1% 미만이면 성공으로 판단하여 반환
  • 모두 실패하면 UTF-8로 폴백

2. extractEpubPreview(newPath: any): Promise<string>

EPUB 파일에서 미리보기 추출 함수

  • JSZip으로 EPUB 파일 압축 해제
  • .opf 파일에서 첫 번째 챕터 경로 찾기
  • 챕터 XHTML 파일 읽기
  • html-to-text로 HTML을 플레인 텍스트로 변환
  • 첫 200자 반환

3. pickFile()

파일 선택 및 추가 함수

  • DocumentPicker로 TXT/EPUB 파일 선택
  • 서버에 중복 체크 요청
  • 중복이면 모달 표시, 아니면 바로 추가

4. addFileToSystem(file: any)

실제 파일 추가 로직

  • 파일을 앱 전용 폴더로 복사
  • 확장자에 따라 미리보기 생성
  • 서버에 파일 정보 저장
  • 로컬 상태 업데이트

5. handleFilePress(file: any)

파일 클릭 핸들러

  • 서버에서 파일 정보 가져오기 (진행도 포함)
  • 진행도 0이면 바로 Reader로 이동
  • 진행도 있으면 이어읽기 미리보기 모달 표시

🪝 주요 Hook 사용

useRouter (expo-router)

화면 간 이동을 위한 라우터 객체

router.push({ pathname: "/reader", params: { fileId, uri, name } });

useLocalSearchParams (expo-router)

URL 쿼리 파라미터 읽기 (폴더 ID)

const { folder } = useLocalSearchParams(); const currentFolder = folder ?? "root";

useMemo

성능 최적화를 위한 메모이제이션

  • filteredFiles: 검색어와 현재 폴더로 파일 필터링
  • visibleFolders: 현재 폴더의 하위 폴더만 표시

useEffect

  1. 컴포넌트 마운트 시 파일/폴더 목록 가져오기
  2. 검색어/폴더 변경 시 표시 개수 초기화
  3. currentFolder 변경 감지 (디버깅용)
