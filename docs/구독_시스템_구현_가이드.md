## Subscription 테이블 설명

```java
@Entity
@Table(name = "subscriptions", indexes = {
    @Index(name = "idx_expires_at", columnList = "expiresAt")
})
public class Subscription {
    private Long id;
    private UserEntity user;       // 로그인 유저 (게스트면 null)
    private String deviceId;       // 게스트 (로그인 유저면 null)
    private Platform platform;     // IOS / ANDROID
    private String planType;       // "monthly" / "yearly"
    private LocalDateTime startedAt;
    private LocalDateTime expiresAt;   // ← 핵심: 만료일
    private SubscriptionStatus status; // ACTIVE / EXPIRED / CANCELLED
    private Boolean autoRenew;
    private String receipt;            // iOS 영수증 (TEXT 타입)
    private String purchaseToken;      // Android 구매 토큰
    private String originalTransactionId; // iOS 최초 구매 ID
    private LocalDateTime createdAt;
    private LocalDateTime updatedAt;
}
```

### 왜 `expiresAt`이 핵심인가?
- `status = ACTIVE`여도 `expiresAt`이 지났으면 프리미엄 아님
- `isPremium` 판단 시 항상 두 가지를 동시에 체크:
  ```java
  status == ACTIVE && expiresAt.isAfter(LocalDateTime.now())
  ```
- 덕분에 Cron Job 없어도 만료가 정확히 처리됨

### `@Index(expiresAt)` 이유
- `/subscriptions/status` API는 매우 자주 호출됨
- `WHERE expiresAt > now AND status = 'ACTIVE'` 쿼리가 핵심
- 인덱스 없으면 구독자 수가 많아질수록 풀스캔으로 느려짐

## API 목록

### 1. `GET /subscriptions/status` — 구독 상태 확인
```
요청: Header { Authorization: Bearer {token} }
      Header { X-Device-Id: {deviceId} }

응답: { "isPremium": true | false }
```
- 앱이 시작될 때, 로그인할 때 자동 호출됨 (`UserContext.checkSubscription()`)
- 네트워크 오류 시 AsyncStorage 캐시 값 사용

---

### 2. `POST /subscriptions/subscribe` — 결제 후 구독 활성화
```
요청: {
  "planType": "monthly" | "yearly",
  "platform": "ios" | "android",
  "receipt": "...",         // iOS
  "purchaseToken": "..."    // Android
}

응답: { "isPremium": true }
```
**흐름:**
1. 앱에서 앱스토어/구글플레이 결제 완료
2. 앱스토어/구글플레이가 영수증(또는 purchaseToken) 발급
3. 프론트가 영수증을 백엔드로 전송
4. 백엔드가 애플/구글 서버에 진짜인지 검증
5. 검증 통과 → DB에 구독 저장 → `{ isPremium: true }` 응답

---

### 3. `POST /subscriptions/webhook/apple` — 애플 자동 알림
- 앱스토어가 서버에 자동으로 POST 전송 (백엔드가 받는 쪽)
- 구독 갱신, 취소, 만료 등의 이벤트 수신
- 수신 후 DB의 `status`, `expiresAt` 업데이트

---

### 4. `POST /subscriptions/webhook/google` — 구글 자동 알림
- Google Cloud Pub/Sub을 통해 전달됨
- 구독 갱신(1), 취소(3), 만료(13) 등 notificationType으로 분기

---

### 5. `POST /subscriptions/test-activate` — 테스트용 구독 활성화
- 실제 결제 없이 DB에 직접 1년짜리 구독 생성
- **배포 전 삭제 필요**

## 애플과의 통신 흐름

```
[유저가 앱스토어에서 결제]
        ↓
[앱스토어가 앱에 영수증(receipt-data) 전달]
        ↓
[앱이 백엔드로 영수증 전송]
        ↓
[백엔드 → 애플 서버로 검증 요청]
  POST https://buy.itunes.apple.com/verifyReceipt
  Body: { "receipt-data": "...", "password": "앱스토어_공유_비밀키" }
        ↓
[애플 서버 응답]
  { "status": 0 }       ← 0이면 유효
  { "status": 21007 }   ← 샌드박스 영수증 (샌드박스 서버로 재시도)
        ↓
[검증 성공 → DB에 구독 저장]
        ↓
[이후 갱신/취소 시]
  애플이 등록된 webhook URL로 자동 POST
  백엔드가 받아서 DB 업데이트
```

**필요한 것:**
- App Store Connect → 앱 내 구입 → 공유 비밀키 발급
- App Store Connect → 앱 정보 → App Store Server Notifications URL 등록

---

## 구글과의 통신 흐름

```
[유저가 구글플레이에서 결제]
        ↓
[구글플레이가 앱에 purchaseToken 전달]
        ↓
[앱이 백엔드로 purchaseToken 전송]
        ↓
[백엔드 → 구글 서버로 검증 요청]
  GET https://androidpublisher.googleapis.com/androidpublisher/v3/
      applications/{packageName}/purchases/subscriptions/{subscriptionId}/tokens/{token}
  (서비스 계정 인증 필요)
        ↓
[구글 서버 응답]
  { "paymentState": 1 }  ← 1이면 결제 완료
        ↓
[검증 성공 → DB에 구독 저장]
        ↓
[이후 갱신/취소 시]
  Google Cloud Pub/Sub → 등록된 백엔드 URL로 자동 POST
  백엔드가 받아서 DB 업데이트
```

**필요한 것:**
- Google Play Console → 서비스 계정 생성 → JSON 키 파일 발급
- Google Cloud Console → Pub/Sub 토픽 생성 → 구독 URL 등록

## isPremium 판단 로직 (SubscriptionService)

```java
public boolean isPremium(UserEntity user, String deviceId) {
    // 1. 로그인 유저면 userId로, 게스트면 deviceId로 조회
    Optional<Subscription> sub = (user != null)
        ? repo.findTopByUserAndStatusOrderByExpiresAtDesc(user, SubscriptionStatus.ACTIVE)
        : repo.findTopByDeviceIdAndStatusOrderByExpiresAtDesc(deviceId, SubscriptionStatus.ACTIVE);

    // 2. 구독이 있고, 만료일이 현재 시각 이후면 true
    return sub.map(s -> s.getExpiresAt().isAfter(LocalDateTime.now()))
              .orElse(false);
}
```

## 프론트 흐름

```
앱 시작
    → UserContext 초기화
    → AsyncStorage에서 로그인 정보 로드
    → checkSubscription() 호출
        → GET /subscriptions/status
        → isPremium 상태 저장
        → AsyncStorage에 캐시

로그인 시
    → login() 호출
    → checkSubscription() 자동 호출

로그아웃 시
    → logout() 호출
    → isPremium = false
    → AsyncStorage 'isPremium' 삭제

프리미엄 기능 접근 시
    → isPremium 체크
    → false면 /subscription 화면으로 이동
```
