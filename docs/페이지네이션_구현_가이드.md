# 페이지네이션 구현 가이드

## 📌 개요

홈 화면의 파일 목록을 **전체 로드 방식**에서 **서버 사이드 페이지네이션**으로 변경하여 성능을 개선했습니다.

---

## 🔄 변경 전 vs 변경 후

### ❌ 변경 전 (전체 로드)
```typescript
// 서버에서 전체 파일을 한번에 가져옴
async function fetchFiles() {
  const response = await fetch(`${BASE_URL}/files`);
  const data = await response.json(); // 전체 1000개
  setFiles(data);
}

// 화면에는 처음 10개만 표시, 스크롤 시 10개씩 추가 렌더링
<FlatList
  data={filteredFiles.slice(0, displayCount)}
  onEndReached={() => setDisplayCount(prev => prev + 10)}
/>
```

**문제점:**
- 파일 1000개 = 5초 로딩 🐌
- 메모리 낭비
- 사용자가 10개만 보고 나가도 1000개 다운로드

### ✅ 변경 후 (페이지네이션)
```typescript
// 필요한 만큼만 서버에서 가져옴
async function fetchFiles(page = 0, reset = false) {
  const response = await fetch(
    `${BASE_URL}/files?page=${page}&size=15&sort=${sortParam}`
  );
  const data = await response.json();
  
  // 첫 페이지면 교체, 추가 페이지면 병합
  if (reset || page === 0) {
    setFiles(data.content);
  } else {
    setFiles(prev => [...prev, ...data.content]);
  }
  
  setHasMore(!data.last); // 마지막 페이지 여부
}

// 스크롤 끝에 도달하면 서버에서 다음 페이지 요청
<FlatList
  data={filteredFiles}
  onEndReached={() => fetchFiles(currentPage + 1)}
/>
```

**개선점:**
- 초기 로딩: 15개만 = 0.1초 ⚡
- 메모리 효율적
- 필요할 때만 서버 요청

## 🛠️ 프론트엔드 수정 사항

### 1️⃣ 상태 관리 변경

**변경 전:**
```typescript
const [displayCount, setDisplayCount] = useState(10);
```

**변경 후:**
```typescript
const [currentPage, setCurrentPage] = useState(0);      // 현재 페이지
const [hasMore, setHasMore] = useState(true);           // 더 가져올 데이터 있는지
const [isLoadingMore, setIsLoadingMore] = useState(false); // 로딩 중인지
```

### 2️⃣ fetchFiles 함수 수정

**주요 파라미터:**
- `page`: 요청할 페이지 번호 (0부터 시작)
- `reset`: true면 첫 페이지부터 다시 로드

**동작 방식:**
1. 정렬 옵션을 서버 형식으로 변환
   - `date-desc` → `date,desc`
   - `rating-asc` → `rating,asc`

2. 서버에 페이지 요청
   ```
   GET /files?page=0&size=15&sort=date,desc
   ```

3. 응답 처리
   - `reset`이면 기존 데이터 교체
   - 아니면 기존 데이터에 추가

4. 마지막 페이지 체크
   - `data.last`가 true면 더 이상 없음

### 3️⃣ useEffect 수정

```typescript
// 초기 로드
useEffect(() => {
  fetchFiles(0, true);  // 첫 페이지 로드
  fetchFolders();
}, []);

// 정렬 또는 폴더 변경 시 리셋
useEffect(() => {
  fetchFiles(0, true);  // 처음부터 다시 로드
}, [sortOption, currentFolder]);
```

### 4️⃣ FlatList 무한 스크롤

```typescript
<FlatList
  data={filteredFiles}  // slice 제거 - 전체 표시
  
  onEndReached={() => {
    // 검색 중이 아니고, 로딩 중이 아니고, 더 있으면
    if (!search.trim() && !isLoadingMore && hasMore) {
      fetchFiles(currentPage + 1, false); // 다음 페이지 로드
    }
  }}
  
  onEndReachedThreshold={0.5}  // 50% 지점에서 미리 로드
  
  ListFooterComponent={() => {
    // 로딩 중일 때 표시
    if (isLoadingMore && !search.trim()) {
      return <Text>로딩 중...</Text>;
    }
    return null;
  }}
/>
```

## 🔧 백엔드 수정 필요 사항

### Spring Boot 예시

```java
@RestController
@RequestMapping("/files")
public class FileController {
    
    @GetMapping
    public Page<FileDto> getFiles(
        @RequestParam(defaultValue = "0") int page,
        @RequestParam(defaultValue = "15") int size,
        @RequestParam(defaultValue = "date,desc") String sort
    ) {
        // sort 파라미터 파싱
        String[] sortParams = sort.split(",");
        Sort.Direction direction = sortParams.length > 1 && sortParams[1].equals("asc") 
            ? Sort.Direction.ASC 
            : Sort.Direction.DESC;
        
        Pageable pageable = PageRequest.of(
            page, 
            size, 
            Sort.by(direction, sortParams[0])
        );
        
        return fileRepository.findAll(pageable);
    }
}
```

### 응답 형식 (Spring Boot Page)

```json
{
  "content": [
    {
      "id": "1",
      "title": "파일1",
      "date": "2026-02-06",
      "rating": 5,
      ...
    },
    ...
  ],
  "totalElements": 500,    // 전체 파일 개수
  "totalPages": 34,        // 전체 페이지 수
  "number": 0,             // 현재 페이지 (0부터 시작)
  "size": 15,              // 페이지 크기
  "last": false,           // 마지막 페이지 여부
  "first": true            // 첫 페이지 여부
}
```

### 폴더별 필터링 (선택사항)

```java
@GetMapping
public Page<FileDto> getFiles(
    @RequestParam(defaultValue = "0") int page,
    @RequestParam(defaultValue = "15") int size,
    @RequestParam(defaultValue = "date,desc") String sort,
    @RequestParam(required = false) String folderId  // 추가
) {
    Pageable pageable = PageRequest.of(page, size, ...);
    
    if (folderId != null && !folderId.equals("root")) {
        return fileRepository.findByPath(folderId, pageable);
    }
    
    return fileRepository.findAll(pageable);
}
```

## ✅ 테스트 체크리스트

- [ ] 초기 로딩 시 15개 파일만 로드되는지 확인
- [ ] 스크롤 끝에서 자동으로 다음 페이지 로드되는지
- [ ] 정렬 변경 시 첫 페이지부터 다시 로드되는지
- [ ] 폴더 이동 시 첫 페이지부터 다시 로드되는지
- [ ] 마지막 페이지에서 더 이상 로드되지 않는지
- [ ] 검색 기능이 정상 작동하는지
- [ ] 로딩 중 표시가 나타나는지

## 🚀 향후 개선 방향

1. **검색도 서버에서 처리**
   - 대량의 파일에서 빠른 검색

2. **캐싱 추가**
   - 이미 로드한 페이지는 재사용

3. **낙관적 업데이트**
   - 파일 추가/삭제 시 즉시 UI 반영

4. **무한 스크롤 최적화**
   - 가상화(Virtualization)로 메모리 더욱 절약
